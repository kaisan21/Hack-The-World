# Hack The World (HTW) - v1.0.0

![License](https://img.shields.io/badge/license-GPL--3.0-red)
![Platform](https://img.shields.io/badge/platform-Kali%20Linux-blue)

**Hack The World** is an all-in-one automation script designed for Kali Linux users to streamline penetration testing workflows. Built by **Kaisan**, this tool provides a professional terminal interface to execute complex security tasks with simple inputs.

## 🚀 Features

- **Network Recon:** Automated Nmap scripts for service detection and OS fingerprinting.
- **Web Pentesting:** Automated SQL injection testing and vulnerability scanning.
- **Wireless Attacks:** Quick-start monitor mode and handshake capturing.
- **Brute Force:** Streamlined Hydra integration for SSH, FTP, and Web Login cracking.
- **Exploitation:** One-touch access to the Metasploit Framework.
